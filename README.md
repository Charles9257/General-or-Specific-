# General or Specific? Reproduction

Code and documentation for a reproduction of Tan, Cao, Li, and Yoshikawa, *General or Specific? Investigating Effective Privacy Protection in Federated Learning for Speech Emotion Recognition* (ICASSP 2023).

- Reproduction scripts, settings, and current status: [`general-or-specific-reproduction/README.md`](general-or-specific-reproduction/README.md)
- Research decisions and deviations: [`general-or-specific-reproduction/reproduction_decisions.md`](general-or-specific-reproduction/reproduction_decisions.md)
- Current pilot results: [`general-or-specific-reproduction/results/pilot_summary.md`](general-or-specific-reproduction/results/pilot_summary.md)
- Dataset notice and license: [`data/README.md`](data/README.md)

The CREMA-D corpus is stored under `data/crema-d/` and tracked using Git LFS. Its original ODbL and Database Contents License notices are retained in the dataset files. The repository's code does not relicense CREMA-D.

No Jupyter notebook was present in the workspace when this repository was prepared; the workflow is currently provided as Python scripts and Markdown documentation.
