# CREMA-D data

This directory contains the CREMA-D multimodal dataset downloaded from Kaggle's [`orvile/crema-d-emotional-multimodal-dataset`](https://www.kaggle.com/datasets/orvile/crema-d-emotional-multimodal-dataset) mirror. The original dataset files and their `README.md` and `LICENSE.txt` are retained at `crema-d/content/CREMA-D/`.

CREMA-D is credited to Cao et al., *CREMA-D: Crowd-sourced Emotional Multimodal Actors Dataset*, IEEE Transactions on Affective Computing, 2014. The dataset is made available under the [Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/) and its individual contents under the [Database Contents License](https://opendatacommons.org/licenses/dbcl/1-0/). Preserve these terms and attribution when using or redistributing it. The code in this repository does not alter or relicense the dataset.

The GitHub repository stores the data through Git LFS. Install Git LFS and clone with LFS support to retrieve the media files.
